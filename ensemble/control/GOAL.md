# Shared goal

Build and improve the declared target project through evidence-driven,
reproducible work while minimizing user relay:

1. three advisors independently analyze and then cross-review;
2. one executor implements the approved plan;
3. all three advisors review the frozen result;
4. deterministic tests and policy gates override popularity;
5. GitHub records validated milestones rather than every conversation.

Each task must add concrete acceptance tests, allowed paths, forbidden actions,
and resource budgets to its own `BRIEF.md`.
